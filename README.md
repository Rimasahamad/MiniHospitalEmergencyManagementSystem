# Mini Hospital Emergency Management System

## Project Description

The Mini Hospital Emergency Management System is a Java-based console application developed for the CIT300 - Data Structures and Algorithms assignment.

The system manages hospital patient records, emergency patients, treatment history, and patient visit history using different data structures.

## Data Structures Used

### 1. Binary Search Tree (BST)
Used for storing and managing patient records.

Functions:
- Insert new patient
- Search patient by Patient ID
- Delete patient record
- Display patients in ascending order of Patient ID

### 2. Queue
Used for managing emergency patients.

Functions:
- Add patient to emergency queue (Enqueue)
- Remove patient for treatment (Dequeue)
- Display waiting patients

Queue follows FIFO (First-In, First-Out).

### 3. Stack
Used for storing completed treatment records.

Functions:
- Add treatment record (Push)
- Remove latest treatment record (Pop)
- Display treatment history

Stack follows LIFO (Last-In, First-Out).

### 4. Singly Linked List
Used for maintaining patient visit history.

Functions:
- Add new visit
- Remove visit
- Search visit
- Display visit history

## Project Features

- Patient registration
- Patient searching and deletion
- Emergency patient management
- Treatment record management
- Patient previous visit tracking
